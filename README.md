Country Top Trumps

A browser-based game where you compare countries on stats such as population, area, and number of bordering nations. Each round presents two random countries, and you choose which one you think has the higher value for a randomly selected statistic.

Live Version
Play the game here: https://countrytoptrumps.netlify.app/

About the API
The original version of the REST Countries API used by this project was deprecated. The site now uses a Netlify serverless function to fetch data from the updated REST Countries v5 API.

Features
- Random country selection each round  
- Three comparison categories: area, population, number of bordering countries  
- Streak tracking  
- SVG flags from REST Countries v5  
- Fully client-side game logic with a serverless API proxy  

Tech Stack
- HTML, CSS, JavaScript  
- Netlify Functions (serverless)  
- REST Countries v5 API
